# ฟังก์ชันและข้อแตกต่างจากโจทย์

เอกสาร PDF ใช้เป็นข้อมูลอ้างอิงด้านความต้องการ ส่วนคำขอผู้ใช้กำหนดให้ปรับรายละเอียดได้ ต้องมีหน้าบ้าน หลังบ้าน ใช้ Remix IDE เผยแพร่ GitHub Pages ออกจากระบบเพื่อสลับบัญชีได้ และมีผลทดสอบพร้อมภาพทุกฟังก์ชัน

| ฟังก์ชันจากโจทย์ | สิ่งที่ทำ | ข้อแตกต่าง / ขอบเขต |
|---|---|---|
| 1. Create Contract | `createJob(title,description,freelancer,amount,deadline)` และฟอร์มภาษาไทย | รวมหลายข้อตกลงในสัญญาเดียว ใช้เลขงาน แทน deploy สัญญาใหม่ทุกงาน ลดขั้นตอนและค่า gas |
| 2. Deposit Payment | ผู้ว่าจ้างฝาก ETH ผ่าน `deposit(id)` ตรวจยอดตรงตามค่าจ้าง | ฝากเต็มจำนวนครั้งเดียว ไม่มีการแบ่งงวดหรือฝากบางส่วน |
| 3. Submit Work | ฟรีแลนซ์ส่ง URL / hash ผ่าน `submitWork` | บันทึกข้อความหลักฐานบน chain ไม่อัปโหลดไฟล์หรือรับรองว่าเนื้อหาตรง hash; แก้หลักฐานได้ขณะรอตรวจรับ |
| 4. Approve & Release | ผู้ว่าจ้างตรวจรับแล้ว `approve` โอน ETH ให้ฟรีแลนซ์ทันที | ไม่มีค่าธรรมเนียมแพลตฟอร์ม และไม่จ่ายอัตโนมัติจากวันที่ส่งงาน ต้องยืนยันจากผู้ว่าจ้าง |
| 5. Dispute Management | ทั้งสองฝ่ายเปิดข้อพิพาทได้ ผู้ดูแลตัดสินผ่าน `resolveDispute` | ใช้ผู้ดูแลเดียวคือ Wallet ที่ deploy สัญญา ตัดสินคืนเต็มจำนวนหรือจ่ายเต็มจำนวน ไม่มีแบ่งสัดส่วน / โหวต / อุทธรณ์ |
| 6. Transaction Tracking | สถานะ ประวัติ จำนวน ETH ผู้ทำรายการ transaction hash และลิงก์ explorer | โหมด Wallet อ่าน Activity events จริง ลิงก์ explorer รองรับ Mainnet/Sepolia; local chain แสดง hash โดยไม่มีลิงก์ ส่วนโหมดสาธิตแสดงรหัส DEMO อย่างชัดเจน |
| กฎห้ามจ่ายซ้ำ | สถานะสุดท้ายไม่รับ approve / resolve / deposit ซ้ำ | ทดสอบทั้งกรณีปกติและการตัดสินข้อพิพาท |
| กฎห้ามถอนก่อนเงื่อนไข | ไม่มี withdraw ทั่วไป จ่ายได้เมื่อ Submitted + employer approval หรือ Disputed + admin resolution | ETH ที่ผู้รับปฏิเสธจะทำให้ทั้งธุรกรรม revert คงยอด escrow เดิม |

## สิ่งที่เพิ่มตามคำขอ

- หน้าภาพรวม หน้าข้อตกลง รายละเอียดและประวัติงาน ประวัติธุรกรรม หน้าตั้งค่าสัญญา และคู่มือ
- หน้าหลังบ้านสำหรับผู้ดูแล ตรวจคู่สัญญา เหตุผล หลักฐาน และตัดสินข้อพิพาท
- ปุ่มออกจากระบบและสลับบัญชีสาธิต ข้อมูลโครงการยังคงอยู่
- Wallet logout ล้าง session ของเว็บ; สิทธิ์ connection ใน MetaMask อาจยังอยู่ ให้สลับบัญชีในกระเป๋าแล้วเชื่อมต่อใหม่ เมื่อ accountsChanged / chainChanged เว็บจะออกจาก session เดิม
- ยกเลิกงานก่อนฝากเงินเท่านั้น (`cancelJob`)
- ค้นหา/กรองสถานะ รีเฟรช คัดลอกรหัสธุรกรรม และจอมือถือ
- โหมดสาธิตที่ใช้เงินจำลองพร้อมตัวอย่าง 4 งาน ช่วยทดสอบโดยไม่มีกระเป๋าหรือ test ETH

## ขอบเขตที่ต้องเข้าใจ

- กำหนดส่งใช้แสดงและติดตาม ไม่มี timeout/refund อัตโนมัติหรือบทลงโทษส่งช้า
- GitHub Pages เป็น static hosting ไม่มี API server/ฐานข้อมูลกลาง หลังบ้านจริงอยู่บน Ethereum
- บัญชีสาธิตและข้อมูล localStorage เปลี่ยนเองได้ในเบราว์เซอร์ เหมาะสำหรับสาธิต ส่วนการใช้งานจริงต้องเข้าโหมด Wallet
- รายละเอียดงานและหลักฐานในโหมด chain เป็นข้อมูลสาธารณะบนเครือข่าย ไม่ใส่ข้อมูลลับในฟอร์ม
- ผู้ดูแลมีอำนาจตัดสินข้อพิพาทเต็มจำนวนตามโมเดลของโครงงาน ไม่มีการเปลี่ยนผู้ดูแลในสัญญารุ่นนี้
- ระบบเป็นโครงงานการศึกษา ยังไม่ได้ผ่านการ audit ภายนอก การทดสอบที่แนบใช้ local EVM และ Remix VM; ไม่อ้างว่าเป็นผลทดสอบ MetaMask extension หรือ Sepolia จริง
- หน้าเว็บโหลดรายการงานและ event history แบบตรงไปตรงมา เหมาะกับข้อมูลระดับโครงงาน หากมีข้อมูลมากควรใช้ indexer และ pagination ก่อนใช้งานขนาดใหญ่
